# kiltak-privacy

KilTak Android uygulamasının gizlilik politikası. / Privacy policy of the KilTak Android app.

Sayfa / Page: https://ramrems.github.io/kiltak-privacy/

KilTak takvim etkinliklerini kilit ekranı duvar kağıdına çizer. Uygulamanın internet izni yoktur; veriler telefondan çıkmaz.

KilTak draws calendar events onto the lock screen wallpaper. The app has no internet permission; data never leaves the phone.
